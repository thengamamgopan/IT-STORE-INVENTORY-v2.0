# IT-STORE-INVENTORY-v2.0
A web database for the IT store: , NAS, L2/L3 switches, routers, modems, access points, firewalls, network printers, printers, scanners, MDF racks, NVRs, CCTV cameras, UPS and anything else you add yourself. Works offline on your office LAN. No internet connection needed. Needs PHP 7.4 or newer and MySQL 5.7+ / MariaDB 10.3+ (any recent WAMP).
